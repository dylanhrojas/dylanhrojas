## 2. **Lipid Classification and Analysis: Mouse vs NMR**
**Description:** Comprehensive analysis of molecular lipid data with supervised classification. Includes data exploration, feature engineering, machine learning model training, and embedding generation for pattern visualization in lipid membranes.  
**Technologies:** Python, NumPy, Pandas, Scikit-learn, XGBoost, t-SNE, UMAP, Jupyter Notebooks  
**Repository:** [GitHub Link](https://github.com/dylanhrojas/mouse-nmr)

**Key Results:** Classification models with F1-score ≈ 1.0 | Embeddings with Silhouette scores (CHOL: 0.598, DPSM: 0.678) | Identification of key discriminant features using XGBoost
